# Simplified Chinese localization

SpatialPlexomera 1.1 includes a Simplified Chinese interface. The application follows the macOS system language by default, with explicit English and Simplified Chinese choices in the `Language/语言` control. The active resources are maintained in [`SpatialPlexomera/zh-Hans.lproj/`](../../SpatialPlexomera/zh-Hans.lproj/).

The localization is part of the canonical application rather than a separate fork. Changing the UI language does not alter the `SpatialPlexomera` product name, source identifiers, file formats, analysis parameters, exported figures, or output schemas, so users can exchange projects reliably.
